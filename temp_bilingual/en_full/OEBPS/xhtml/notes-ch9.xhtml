  4.   4.  More technically, DeepMind’s program used what is called an epsilon-greedy method for choosing an action at each time step. With probability epsilon the program chooses an action at random; with probability (1 − epsilon) the program chooses the action with the highest value. Epsilon is a value between 0 and 1; it is initially set close to 1 and is gradually decreased over the episodes of training.
