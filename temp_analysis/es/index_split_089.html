UBICACIONES

Acharnae ( ah-KAR-nigh ) –

Pequeño pueblo sitreciano.

Agerus ( ah-GAIR-us ) –

La región cercana a Caten donde se encuentra la Necrópolis.

Alta Semita ( AHL-tah sem-EE-tah ) –

Un distrito de Caten.

Aquiria ( ah-KEER-ee-ah ) –

Pequeño país fronterizo con Suus. El país donde Vis afirma oficialmente haber nacido.

El acantilado de Aznaro

Un acantilado con vistas al océano en Suus.

Butaria ( boo-TAH-ree-ah ) –

Una región marítima al oeste de Caten.

Cartiz ( kar-TEEZ ) –

La capital aquiriana, cerca de la cual Vis afirma haber crecido.

Caten ( cah-TEN ) –

Capital de Deditia y de la República de Catenana, considerada el centro del mundo conocido.

Academia Catenan ( cah-TEN-an ) –

La Academia a la que asiste Vis, ubicada en la isla de Solivagus.

Arena Catenan ( cah-TEN-an ) –

El gran estadio de Caten con capacidad para cien mil personas.

República de Catenan ( cah-TEN-an ) –

El nombre utilizado para describir cualquier región gobernada por las leyes de Caten.

Cymr ( KYE-meer ) –

País situado al suroeste de Caten.

Deditia ( deh-DEE-chee-ah ) –

La región que rodea inmediatamente a Caten.

Deópolis ( dee-OP-oh-liss ) –

La capital de Sytrece.

Río Edaro ( ed-AH-roe ) –

Un río en Aquiria.

Estrecho de Eldargo ( el-DAR-go ) –

El tramo de agua que separa Suus de Aquiria.

Esquilae ( ESS-kil-igh ) –

Un distrito de Caten.

Ganice ( GAH-niss ) –

Un territorio catenano.

Guridad ( GOO-ree-dad ), Puerto –

Una ciudad comercial de Aquiria, ubicada frente a Suus en el estrecho de Eldargo.

Jatiere ( YAH-tee-air ) –

País cuyo tratado restringe a los embajadores catenanos allí el uso de la voluntad.

Letens ( leh-TENS ) –

Capital de Tensia.

Prisión de Letens ( leh-TENS ) –

La prisión en la que trabaja Vis.

Columna de Lordan ( lor-DAHN ) –

Un famoso monumento en Caten.

Luceum ( loo-KEY-um ) –

Un lugar misterioso, generalmente referenciado junto a Res y Obiteum.

Lyceria ( ligh-KEER-ee-ah ) –

Un territorio catenano.

Masen ( MAH-sen ) –

Un territorio catenano.

Necrópolis ( neh-KROP-oh-lis ) –

Una gran zona dedicada a los muertos de Catenan, situada en la región de Agerus.

Nyripk ( NEER-ik ) –

País desértico situado más al noreste.

Obiteum ( oh-bit-EE-um ) –

Un lugar misterioso, normalmente mencionado junto a Res y Luceum.

Praedium ( PRIG-dee-um ) –

Distrito de Caten.

Quus ( COOS ), Mar de –

El mar en el que se encuentran Solivagus y Caten.

Res ( REZ ) –

Un lugar misterioso, generalmente referenciado junto a Obiteum y Luceum.

Sarcinia ( sar-KIN-ee-ah ) –

Distrito de Caten.

Playa Solencio ( sol-EN-see-oh ) –

Una playa en Suus.

Solivagus ( soh-liv-AH-gus ) –

Isla en la que se encuentra la Academia.

Suus ( SOOS ) –

La isla natal de Vis.

Sytrece ( sit-REES ) –

País al este de Deditia.

Tensia ( TEN-see-ah ) –

El país más poblado del sur del mundo conocido.
