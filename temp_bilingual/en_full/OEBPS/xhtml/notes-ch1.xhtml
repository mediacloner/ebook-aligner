  17. 17.  Mathematically, the perceptron-learning algorithm is the following. For each weight wj: wj ← wj + η (t − y) xj, where t is the correct output (1 or 0) for the given input, y is the actual output of the perceptron, xj is the input associated with weight wj, and η is the learning rate, a value given by the programmer. The arrow signifies an update. The threshold is incorporated by creating an additional “input” x0 with a constant value of 1, whose associated weight w0 = −threshold. With this added input and weight (called the bias), the perceptron fires only if the sum of the inputs times weights (that is, the dot product between the input vector and the weight vector) is greater than or equal to 0. Often the input values are scaled and other transformations are applied in order to keep the weights from growing too large.
